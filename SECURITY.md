# Security Policy

Found a security issue in [Cartograph](https://github.com/onixhdz/cartograph)? Read on.

## Reporting a Vulnerability

Maintainers will attempt to respond to/confirm reports within 2-3 days, but if you believe your report to be "critical" to user safety and security, please note as such in the subject.

When reporting an issue, where possible, please provide at least:

* The project and commit version the issue was identified at
* A proof of concept (plaintext; no binaries)
* Steps to reproduce
* Your recommended remediation(s), if any.

The cartograph team is a volunteer-only effort, and may reach back out for clarification.

### Report Privately

Do not report vulnerabilities through public GitHub issues.

Use GitHub's private vulnerability reporting flow from the repository's `Security` tab, then click `Report a vulnerability` and fill out the form. Reports submitted this way are visible only to maintainers until disclosure is coordinated.
